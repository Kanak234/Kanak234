# Kanak Prabhakar

Systems, security, and applied-AI developer. I build across a wide stack — a
programming language in Rust, security scanners, space-science tooling, offline
AI platforms, and desktop/VS Code developer tools.

Most of what I build runs **offline and local-first**: no cloud dependency, no
API key required, usable on modest hardware.

## Main work

### Languages & developer tools
- **[klions](https://github.com/Kanak234/klions)** — an AI-first systems programming language where tensor shapes are part of the type. Rust, multi-crate workspace, VS Code tooling. *([docs](https://github.com/Kanak234/klion) · [naamkaran](https://github.com/Kanak234/naamkaran), its workspace rename tool)*
- **[kp-vscode-extensions](https://github.com/Kanak234/kp-vscode-extensions)** — a pnpm monorepo of VS Code extensions: architecture graphing, AST analysis, systems tooling.
- **[vyuha](https://github.com/Kanak234/vyuha)** — run code in any language and watch the structure it builds.
- **[bodha](https://github.com/Kanak234/bodha)** — a VS Code extension that explains what your code is actually doing.
- **[inference-graph](https://github.com/Kanak234/inference-graph)** — renders a neural-network spec as a live 3D graph.
- **[vidyut](https://github.com/Kanak234/vidyut)** · **[prabha](https://github.com/Kanak234/prabha)** — write Turbo C graphics in VS Code, and compile Borland-era coursework with a modern compiler. No DOSBox.
- **[neuralschema](https://github.com/Kanak234/neuralschema)** — universal code and system-architecture analyzer.

### Security
- **[pyrastride](https://github.com/Kanak234/pyrastride)** — turns a flat list of scanner findings into a STRIDE threat model, re-ranked by threat weight.
- **[pyrasec-pyramid](https://github.com/Kanak234/pyrasec-pyramid)** — interactive 3D WebGL viewer for codebases and vulnerability trees.
- **[tools-cyber-security](https://github.com/Kanak234/tools-cyber-security)** · **[network-scanning-tool](https://github.com/Kanak234/network-scanning-tool)** — standalone security utilities.
- **[bhandar](https://github.com/Kanak234/bhandar)** — batch-publishes projects to GitHub, refusing to push anything until a secret scan passes.

*Also, kept private for now: **PyraSec**, a static scanner for secrets, IaC, containers and dependencies with SARIF and SBOM output — the engine `pyrastride` and `pyrasec-pyramid` are built on.*

### Space & astronomy
- **[vyomnetra](https://github.com/Kanak234/vyomnetra)** — offline-first Space Situational Awareness workbench: orbit tracking and conjunction analysis on SGP4.
- **[exopipe](https://github.com/Kanak234/exopipe)** — finds transiting-planet signals in noisy TESS light curves.
- **[apollo-sim](https://github.com/Kanak234/apollo-sim)** — Apollo Lunar Module descent, orbital and Mars-transfer simulators, with a full lander physics package.
- **[isro-ch-07](https://github.com/Kanak234/isro-ch-07)** — end-to-end exoplanet detection, built for an ISRO space-science challenge.

### Applied AI
- **[product-intelligence](https://github.com/Kanak234/product-intelligence)** — turns a loose product description into structured, validated catalogue data.
- **[legal-ai](https://github.com/Kanak234/legal-ai)** — containerised, offline-capable legal research and analytics platform.
- **[tchva](https://github.com/Kanak234/tchva)** — AI climate early-warning and crop advisory for smallholder farmers.
- **[roadpipe](https://github.com/Kanak234/roadpipe)** — occlusion-robust road extraction plus graph-theoretic criticality analysis.
- **[gimp-llm-editor](https://github.com/Kanak234/gimp-llm-editor)** — describe the edit; a local Ollama model turns it into GIMP operations.
- **[dristi](https://github.com/Kanak234/dristi)** — KSP Datathon 2026 entry: crime hotspot maps, risk prediction, patrol allocation.

*Kept private for now: **ERA-AI** (local-first personal AI over several Ollama models), **GPUForge** (heterogeneous multi-GPU training orchestrator), **irpipe** / **irvision** (thermal-IR colourisation and super-resolution), **medha-ide** (offline-first AI development environment), **LiveTalk** (real-time speech translation on a phone call).*

### Simulation & games
- **[vajra-tactical-engine](https://github.com/Kanak234/vajra-tactical-engine)** — a playable tactical infiltration game and its engine, written from scratch in C++20.
- **[hazaribagh-open-world-3d](https://github.com/Kanak234/hazaribagh-open-world-3d)** — a browser 3D open-world engine mapped to real Hazaribagh streets.
- **[ShilpLoka](https://github.com/Kanak234/ShilpLoka)** — an Ancient-Indian-themed voxel sandbox.
- **[smart_traffic](https://github.com/Kanak234/smart_traffic)** — pygame rewrite of the classic smart street-light simulation.
- **[zon](https://github.com/Kanak234/zon)** — a cyberpunk card game with world anomalies and persistent campaigns.

### Research & teaching
- **[github-research-dataset](https://github.com/Kanak234/github-research-dataset)** — a verified, deduplicated dataset of 668 actively-maintained, licensed open-source repositories, built from the GitHub API and reproducible from the included script.
- **[ABHYAS](https://github.com/Kanak234/ABHYAS)** — an offline AI/ML learning tool for students in Hazaribagh, built to run even on Windows 7.
- **[universal-ide](https://github.com/Kanak234/universal-ide)** — a browser coding environment for students: C, C++, Java, Python, JavaScript, HTML, CSS.
